# 📊 Retail Sales Analysis & Reporting Dashboard

## 📌 Project Overview
This project analyzes the Superstore Retail Sales dataset using **Excel, Python, and Power BI**. The objective is to clean the data, analyze sales performance, calculate key business metrics, and build an interactive dashboard that helps businesses make data-driven decisions.

---

## 🛠️ Tools & Technologies
- Microsoft Excel
- Python (Pandas, Matplotlib)
- Google Colab
- Power BI

---

## 📂 Dataset
- Superstore Retail Sales Dataset
- Total Rows: **9,994**
- Total Columns: **21** 0

## 💡 Key Insights
- West region generated the highest sales.
- Technology category achieved the highest profit.
- Higher discounts negatively affected profitability.
- Sales showed seasonal trends. 6
